# TapTap H5 发布核对

仅在目标平台是 TapTap 时使用。以下为 2026-10-29 至 2026-10-30 归档的接口行为和控制台观察，不代表将来版本的永久契约。实际操作前检查当前官方文档、控制台和已安装 MCP 实现。

官方入口：
- [MCP 接入](https://developer.taptap.cn/minigameapidoc/quick-start/mcp-guide/mcp-setup/)
- [小游戏开发文档](https://developer.taptap.cn/minigameapidoc/)

## 有副作用的接口

| 观察对象 | 当时发现 | 执行前的处理 |
| --- | --- | --- |
| create_app | 创建后可处于未发布状态 | 只在已有创建授权时执行；返回后读实际状态 |
| update_app_info | 更新基础资料后，曾从未发布变为审核中 | 不把它当纯草稿保存；先查现版本行为及授权 |
| 官方 MCP 1.24.14 的 upload_h5_game | 上传完成后调用 /level/v1/submit，没有仅上传草稿选项 | 仅授权更新包体时不能据此自动提交审核 |

如果本次授权不含隐含副作用，完成本地可审查产物，说明具体接口和原因，交由用户操作或等待明确授权。不要自行撤回已有审核来补救，也不要绕到另一个自动提交接口。

应用选择可能与当前项目不同。先读当前应用和可用应用列表，用当前项目已确认的信息核实目标；不把旧项目 ID 固化进 skill。授权失效时通过官方流程重新授权，链接过期不能继续复用，不将短期链接、二维码或凭证写入源码与文档。

## 包体与启动

当时 H5 上传界面提示：仅 ZIP，最大 300 MB；解压后根目录只有一个文件夹，文件夹内包含 index.html。曾出现平铺 index.html、assets、licenses 三个根条目导致解析失败。

正确结构示意：

```text
任意单一目录/
  index.html
  assets/
  licenses/
```

300 MB 是该上传界面的容量提示，不等同于首包、审核、性能或项目预算。不能把其他小游戏运行模式、Unity 模式或分包文档的限额直接套到 H5 ZIP。

H5 需要按平台提供的托管入口验证启动与子目录资源加载，不要求玩家启动开发者的本地服务。文件结构验证通过也不等同于平台或设备启动验证通过。

## 广告与物料

按当前应用读取广告开通状态、广告位与官方接入指南，再使用当前 SDK。既有接入曾使用 `tap.createRewardedVideoAd`；回调与参数仍需按当前官方文档核对。集成细节与验收读 [rewarded-ads.md](rewarded-ads.md)。

游戏 Logo 与应用图标不能混用规格。曾有 Logo 因非透明背景被退回，应检查 PNG 的真实 alpha 和边缘效果；尺寸、大小、宣传图比例与录屏要求按当前控制台字段逐一核实。

操作结束记录应用、版本、返回状态和做过的动作。没有执行审核或发布就明确说明，不能写“已更新上线”。
