# 游戏发布资料整理

用户要“给我这个游戏的发布资料”时，先从当前游戏工作区查找 `release/<平台>/README.md` 或项目已有发布目录。确认项目、版本、目标平台和构建。已有资料仍准确时直接整理路径与可粘贴文案，版本变化时只更新有差异的部分。素材和项目文案保存在项目发布目录，skill 只保存整理方法与规格入口。

## 交付物

- 独立整理游戏简介、首页推荐语、开发者的话、更新日志。简介前段说清真实类型和核心循环。推荐语写一条与实机玩法相符的短句。开发者的话说设计选择和体验，避免重复简介或虚构开发经历。更新日志只列对应版本的实际改动。各字段遵守目标平台的文案限制。
- 列出平台必填、按发布状态或屏幕方向触发、按平台功能选填的素材。交付可直接选中的图片和视频，不只给尺寸列表或提示词。区分应用图标、独立透明 LOGO、带标题宣传图和无字图。
- 宣传主视觉与游戏内美术和角色一致，构图为各比例裁切保留标题、角色与 UI 安全区。记录源图、标题层和生成提示，便于下版改尺寸。截图和录屏使用当前实际构建和隔离存档，展示核心玩法。
- 用解码工具验证交付文件的实际尺寸、宽高比、格式、透明度、体积、张数、视频编码与时长。首帧、核心玩法片段、标题裁切和截图重复也要看实物。索引逐项记录文件名、用途、规格、版本和来源，提供目录或压缩包及文案入口。
- 本流程止于本地资料整理与交付。创建游戏另走明确授权的厂商和应用流程。上传、保存后台资料、提交审核和发布需有相应授权。

## 实机录屏制作

后续小游戏制作实机录屏时，先录制一条覆盖大多数主要功能的长视频，保留素材原片。再从中剪出约 1 分钟的实机成片，开头直接展示核心玩法，并用游戏自己的背景音乐配乐。按目标平台要求验收画幅、编码和时长。

## TapTap 小游戏

实际整理时核对 [商店游戏物料要求](https://developer.taptap.cn/docs/store/release/publish/material/)、[小游戏宣发物料指引](https://developer.taptap.cn/minigameapidoc/quick-start/guide/game-publish/material/)、[商店审核细则](https://developer.taptap.cn/docs/store/release/publish/agree/) 和 [小游戏审核规范](https://developer.taptap.cn/minigameapidoc/tap-operation/operation-standards/review-standards/)。两份尺寸要求同时适用时按更严格的值出图，并对照实际后台字段。下列为 2026-11-06 核对的制作基准。

| 物料 | 制作基准 |
| --- | --- |
| 图标 | 512×512 起，PNG 或 JPG，直角方图和彩色不透明背景 |
| 横版宣传图 | 1920×1080，PNG 或 JPG，小游戏不超过 2 MB。仅有游戏标题，主体和标题留在居中 4:3 安全区 |
| 方形宣传图 | 1440×1440，PNG 或 JPG，小游戏不超过 2 MB。与横版宣传图主体一致，竖版实机视频使用 |
| 实机截图 | 至少 3 张，PNG 或 JPG，小游戏单张不超过 2 MB。同方向、同比例，横版可做 1280×720，竖版可做 720×1280，真实核心画面排在前面 |
| 实机录屏 | MP4、H.264 或 HEVC，小游戏上限 500 MB。横版 16:9 且至少 1280×720，竖版 9:16 且至少 720×1280。时长大于 15 秒且不超过 30 分钟，开头 5 秒内出现核心玩法并连续展示超过 10 秒。使用游戏原画面，无前贴片、外加旁白字幕、水印、设备外框或画中画 |
| 独立游戏 LOGO | 透明 PNG，宽 1280 或高 720，4 MB 内。紧贴图形裁透明留白，保留抗锯齿边缘 |
| 电脑或主机封面 | 横版 460×215、竖版 600×900，PNG 或 JPG，各 3 MB 内。含标题，无其他宣传字样 |
| 游戏库壁纸 | 3840×1240，PNG 或 JPG，10 MB 内。无标题或文字，左下与右上避开重要主体 |
| Windows 无字宣传图 | 横版 1920×1080 起、竖版 720×1080 起，PNG 或 JPG，各 6 MB 内。成对，主体相近，无标题或文字 |
| 横版宣传片 | 16:9，1280×720 起，优先 1920×1080。H.264 或 HEVC，MP4 或 MOV，5 GB 内，至少 15 秒。开头直接展示核心玩法 |
| 首页编辑推荐栏目图 | 1920×1280，PNG 或 JPG，建议附 PSD 源稿。只在获得编辑推荐资格后走相应工单，普通发布时可归入备用资料 |

首页推荐语需与游戏玩法相关，避免商业宣传、极限词、模糊日期和未授权 IP。推荐语、推荐素材选项和编辑推荐栏目图是不同字段。资料包说明可用的推荐素材，实际勾选和提交由授权范围决定。电脑端物料和编辑推荐图标明适用场景，不写成普通小游戏的必填项。
