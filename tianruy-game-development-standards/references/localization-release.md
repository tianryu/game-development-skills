# 本地化与交付细则

## 玩家文案

- 描述、提示、选项、日志、状态和数值预览都遵守当前规则。展示简洁不能省略会影响操作判断的条件、范围、代价、次数及例外。
- 通用术语从统一词条解释，正文保留该内容特有信息；无实际能力或状态时不为填空写“无特殊效果”等占位句。
- 行动、代价和结果各出现于合适位置，避免标题与说明重复。玩家不需要的内部层级、序号、实现细节留在开发文档；正式玩法术语不因含相同字词被误删。
- UI 设计稿、原型、英文与正式界面同样遵守文案规范，不把问题留到实装才纠正。只更新规范不等于存量界面已全部修复。
- 修改实体名称或规则时按稳定 ID 核对正文、提示、日志、预览、相关引用和当前校对栏。保留历史记录及用户填写栏，不能重导覆盖用户审核内容。
- 用户编辑中的审核表以最新保存版本为准；检测到并发保存时停止覆盖，重新取得最新文件，必要时请用户完成保存并关闭后再合并。

## 多语言条件专项

仅对项目已支持或本批已授权的语言执行。不要求每个项目都实现英文，也不擅自新增语言。

- 玩家可见文案的新增、修改和删除，同批维护支持的语言；源文案、译文和生成的运行资源在同一交付/提交中一致。
- 使用项目唯一正式译文入口，运行目录、PO/资源表、来源索引和校对页由工具生成，不直接手改生成文件。历史译文清单不能冒充当前覆盖范围。
- 术语表统一同一概念，按语境处理同词不同义、单复数、专名及显示名称；不能机械从代码 ID 生成译名。专名需来源时核对真实依据，不冒称已核对原典或权威译本。
- 对齐数值、对象、触发时机、持续/频率、随机范围、费用、否定、上限和例外；覆盖本批涉及的所有变体与动态拼接完整句。
- 翻译只作用于显示层，不能改稳定 ID、内部规则标签、存档值或资源路径。删除失用译文前检查共享引用。
- 动态句使用明确参数边界与占位符的模板，核对类型和顺序。富文本标签与参数保持合法；尽量先得到完整翻译再局部着色，避免碎片拼接无法匹配。
- 语言切换应可恢复原语言布局，只改变显示。重绘、自绘文本、长名称、换行与按钮尺寸都读取当前语言，不重新执行领取、购买或进度流程。
- Godot 自动翻译控件保留源文本或项目约定的翻译键，不把已翻译字符串永久写回当新源；具体格式化 API 沿用当前项目。
- 执行当前项目本地化构建与只读校验，并核对本批相关实际显示；不能只刷新快照、扩大排除项或登记假翻译掩盖漏译。
- 排版检查、机器校验和语义审读分开报告。能显示英文不代表母语审校，也不代表所有流程通关。

## 开发文件与运行依赖

- 开发工具、Excel、测试脚本、报告、预览与临时输出放在明确的非发行目录；发布所需配置和生成数据放在正式运行目录。
- 宣传制作文件与游戏运行资源分开管理，不把视频工程、录制缓存或工具依赖塞进游戏运行目录。
- 版本控制忽略、引擎导入忽略、导出排除分别配置。工具的依赖目录及符号链接不能绕过隔离进入引擎导入或发行包。
- 正式运行依赖需维护保护清单或等价规则。目录名叫 docs、tools 或 tests 不足以判断其中内容能否排除，先核对实际运行引用。
- 使用原始源文件生成运行资源，保留来源与必要许可。转换时以原始源文件为准。美术、音频和字体来源遵循 [美术与素材制作细则](art-production.md)，具体格式和压缩预算由项目决定。

## 第三方素材与鸣谢

- 登记实际使用的第三方素材名称、作者、原始来源、许可或授权、必要署名、修改情况和运行引用。字体与音频也纳入登记。
- 游戏使用任何开源素材时，设置玩家可打开的「鸣谢」菜单，列出实际采用的开源素材及作者，按许可证补齐链接、版本或署名措辞。菜单以外，仍按许可保留需要随包提供的许可证和声明。用正式入口打开鸣谢并核对它与实际包内容。

## 替换、归档与删除

- 替换文件先检查正式配置、直接引用、动态加载、共享回退和仍使用的预览；仅静态搜索无结果不证明没有使用。
- 确认停用的文件按项目约定隔离归档，记录原路径、替代路径、原因及必要哈希；核验副本后再移除正式副本及确属独占的派生产物。
- 不能把仍共享的文件或缓存一起删除，也不能把一次替换扩展为未经授权的大规模清理。需要不可恢复删除时确认已获相应范围授权。
- 暂存可再生成内容在本批结束时清理；具有用户手工修改、独占来源或复现价值的内容不能按临时缓存处理。

## 构建与发布

- 仅在任务包含构建或发行时执行对应流程。先确认目标平台、版本分支、导出配置和正式依赖，不能因功能开发完成就自行发布。
- 测试入口在正式构建中不仅隐藏，还应排除或拒绝调用；不能把调试捷径当作正式完成路径。
- 检查实际导出包的文件与许可证，必要时在干净目录启动并验证相关加载、设置及存取。源码大小、Git 大小和缓存大小都不能冒充发行体积。
- 本机或编辑器通过不代表发行程序、其他操作系统或图形后端通过。无法执行的目标平台明确标记待测。
- 代码合并、提交或推送不会更新已经导出的安装包；包更新、上传和上架分别核实，不能在交付说明中混写。
- 新增资源或运行依赖时更新现有导入/发行校验规则；不能禁用校验、重置验收基线或扩大忽略范围来掩盖问题。
